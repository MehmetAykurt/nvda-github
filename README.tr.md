# NVDA için GitHub

[Türkçe](README.tr.md) | [English](README.md)

GitHub işlemlerini klavye ve ekran okuyucuyla erişilebilir biçimde yürütmek için geliştirilen bir NVDA eklentisidir. Türkçe ve İngilizce dil desteği sunar.

Hesap bağlantısının ilk uygulaması hazırlanmıştır. Depo yönetimi, dosya yükleme ve sürüm yayımlama işlemlerinin eklenmesi planlanmaktadır.

Geliştirme devam etmektedir. Bu depoda şimdilik yalnızca tanıtım belgeleri yer almaktadır; kaynak kodları ve kurulabilir sürümler henüz burada yayımlanmamıştır.
