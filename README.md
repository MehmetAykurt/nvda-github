# GitHub İçin NVDA Entegrasyonu

Dünyanın en büyük kod ve dosya barındırma platformu olan GitHub'ın web sitesindeki karmaşık, dağınık ve ekran okuyucuyla takibi zor olan yapısını tamamen ortadan kaldırarak görme engelli kullanıcılara kusursuz bir masaüstü deneyimi sunar.

---

## Eklentinin Sunduğu Özellikler

- Hesaba Güvenli Bağlanma
- Depo Yönetimi
- Çalışma Dalları Yönetimi
- Dosya ve Klasör İşlemleri
- Erişilebilir Dahili Dosya Düzenleyici
- İşleme Geçmişi ve Değişiklik İnceleme
- Çekme İstekleri ve Kod Birleştirme
- Sorun, Hata ve Görev Takibi
- Sürümler ve Kurulum Paketi Dağıtımı
- NVDA Eklenti Mağazası'na Eklenti Gönder
- Bildirim Merkezi
- Açık Kaynak Projeleri Keşfetme ve Arama

---

## Kullanım

Eklenti arayüzüne aşağıdaki yöntemlerle hızlıca erişebilirsiniz:
- **Kısayol Tuşu:** `NVDA+G`
- **NVDA Menüsü:** `NVDA Menüsü -> Araçlar -> GitHub`
