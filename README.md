# GitHub for NVDA

[English](README.md) | [Türkçe](README.tr.md)

An NVDA add-on being developed to make GitHub management accessible from the keyboard, with English and Turkish language support.

The initial account-connection implementation is prepared. Planned features include repository management, file uploads and release publishing.

Development is ongoing. This repository currently contains introductory documentation only; source code and installable releases have not yet been published here.
